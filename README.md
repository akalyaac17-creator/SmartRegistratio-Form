# Smart Registration Form

A simple and interactive registration form developed using **HTML, CSS, and JavaScript**.

## 📌 About the Project

The Smart Registration Form allows users to enter their personal information through a user-friendly registration form. The application performs real-time validation and dynamically displays the submitted information in a table.

## ✨ Features

* Real-time form validation
* Character counter for the Bio field
* Required field validation
* Dynamic table row creation
* Form submission without page refresh
* Clean and responsive user interface
* User-friendly error messages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript


## 🎯 Project Objective

The main objective of this project is to practice **HTML forms, CSS styling, JavaScript validation, DOM manipulation, and dynamic data handling**.
